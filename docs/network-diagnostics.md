# 网络诊断

网络诊断页从主机页顶部或单台主机的连接工作区进入。全局入口允许输入域名/IP 和端口；主机入口根据保存的连接方式自动选择第一个实际连接节点，并锁定目标，避免绕过代理或跳板机进行误导性的直连测试。

## 检测内容

- 显示系统当前可用的 Wi-Fi、以太网、蜂窝和 VPN 网络，并允许选择测试所使用的网络。
- 显示接口地址、网关、DNS、MTU、私人 DNS、系统代理、计费状态、互联网验证和登录门户状态。
- DNS 解析绑定到所选 Android `Network`，超时窗口为 5 秒。
- TCP 连接固定采样 5 次，间隔 300 毫秒，单次总超时 3 秒；结果汇总最小、平均、最大连接耗时与连接失败率。
- 对 SSH 节点读取一次服务 Banner；端口可连接但没有 Banner 时，只提示可能不是 SSH 或响应较慢，不把它解释为身份可信或认证成功。

TCP 连接失败率不是 ICMP 丢包率。本功能不执行 ICMP Ping、traceroute、带宽测速、后台监控，也不保存或上传诊断结果。

## 代理与跳板机

首版只验证设备到连接路径中第一个节点：

- 直连主机检测目标 SSH 地址与端口。
- 配置 HTTP/SOCKS5 代理时检测代理地址与端口。
- 配置跳板机时检测跳板机；如果跳板机自身配置代理，则检测该代理。

诊断不会读取或解密凭据，不会执行代理认证、SSH 用户认证或跳板后的目标连接，也不会添加、删除或自动信任主机密钥。

## 结果解释

- “未验证互联网”只表示 Android 没有确认公网连通性，不代表局域网 SSH 不可用。
- DNS 成功但所有 TCP 样本失败时，应检查端口、防火墙、服务监听地址和路由。
- 部分样本失败表示连接不稳定，也可能由网络切换、拥塞或服务器限流造成。
- 登录门户状态表示当前网络可能需要先在浏览器中完成认证。

## Android 权限

当前应用目标为 Android 16 / SDK 36，局域网访问继续由已有的 `INTERNET` 权限隐式允许，因此本版不新增附近设备权限。

应用未来升级到 Android 17 / target SDK 37 时，直接连接局域网地址需要声明并在运行时申请 `ACCESS_LOCAL_NETWORK`。诊断引擎已经将系统权限拒绝单独分类，届时应在局域网扫描与网络诊断入口统一接入权限申请和拒绝处理。
