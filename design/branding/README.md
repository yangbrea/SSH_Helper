# SSH Helper launcher icon

The selected direction uses a white base, a youthful sky-blue/periwinkle shield,
the established `>_` terminal mark, and a small orbital path representing secure
routing and tunnelling.

- `concepts/young-orbit-shield-imagegen-reference.png`: approved Imagegen source artwork.

The packaged adaptive foreground is derived from the approved artwork with its
outer white field removed and its visible content fitted to the central safe zone.
Legacy square and round PNGs are also rendered from this same source. Android 13's
monochrome mask uses the source silhouette and turns the terminal mark into negative
space; no alternative geometry is redrawn.
